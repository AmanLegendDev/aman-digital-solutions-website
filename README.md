## 🧠 Architecture

The project follows a modern full-stack Next.js architecture with a strong focus on:

- Component-based development
- Server-first rendering where appropriate
- Reusable UI components
- Dynamic database-driven content
- Type-safe development
- SEO-friendly routing
- Performance optimization
- Secure server-side operations
- Scalable content management

The application uses the **Next.js App Router** and separates public-facing experiences from administrative functionality.
